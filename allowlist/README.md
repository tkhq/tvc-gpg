# Allowlist

These files come from `team/gpg/*.asc` in the `tkhq/keys` repo. `KEYS_COMMIT` names the commit they come from.

To refresh, copy the files again from a clean checkout of `tkhq/keys`, then write the new commit hash into `KEYS_COMMIT`.

Add only team keys here. Never add a key from `shared/gpg` or `superadmin/gpg`.
